Mise en forme

Tout ce que l'on peut écrire dans une note ObsiLan. Pour chaque élément, à gauche ce qu'il faut taper, à droite le résultat en mode lecture. Ces syntaxes sont celles d'Obsidian : vos notes restent compatibles.

Dans l'application, ce guide existe aussi sous forme de note : bouton Guide en bas de la barre latérale, ou palette de commandes (Ctrl+P) → « Guide de mise en forme ». Passez en lecture avec l'œil, en modification avec le stylo (ou Ctrl+E).

Liens entre notes

Ce que vous tapezRésultat
[[Recettes]]Recettes
[[Recettes|mes recettes]]mes recettes (texte affiché différent)
[[Recettes#Desserts]]Recettes#Desserts (vers un titre de la note)
[[Note pas encore écrite]]Note pas encore écrite (note à créer)
  • Tapez [[ : l'application propose les notes existantes.
  • Un lien vers une note qui n'existe pas encore apparaît en pâle ; un clic la crée.
  • En mode modification, Ctrl+clic ouvre le lien.
  • Renommer ou déplacer une note met à jour tous les liens qui y mènent.
  • Les rétroliens, sous chaque note, listent les notes qui pointent vers elle ; le graphe les dessine.

Tags

#recette #projets/maison
#recette #projets/maison
  • Un tag commence par #, sans espace. Le / crée des sous-tags.
  • L'onglet Tags de la barre latérale les liste tous ; un clic affiche les notes du tag.

Modèles et note du jour

  • Alt+D ouvre la note du jour.
  • Alt+T insère un modèle : une note rangée dans le dossier Modèles.
  • Variables des modèles : {{title}}, {{date}}, {{time}}, {{date:dddd D MMMM YYYY}}.
