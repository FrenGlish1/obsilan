Sur Windows

Configuration requise : Windows 10 ou 11 (64 bits).

  1. Téléchargez l'installeur : ObsiLan pour Windows (.exe).
  2. Lancez-le. Windows peut afficher « Windows a protégé votre ordinateur » : l'application n'est pas signée par un éditeur commercial. Cliquez sur Informations complémentaires puis Exécuter quand même. Aucun droit administrateur n'est demandé.
  3. Choisissez le dossier de vos notes au premier lancement : Documents\ObsiLan par défaut, ou un dossier existant.

Pour changer de dossier plus tard, cliquez sur son nom en bas de la barre latérale.

Sur Android

Configuration requise : Android 7 ou plus récent.

  1. Téléchargez le fichier depuis le téléphone : ObsiLan pour Android (.apk).
  2. Ouvrez-le depuis les téléchargements. Android demande d'autoriser l'installation d'applications provenant de cette source (navigateur ou gestionnaire de fichiers) : acceptez, puis touchez Installer.
  3. Autorisez l'accès aux fichiers au premier lancement : Android ouvre le réglage Accès à tous les fichiers. Activez-le pour ObsiLan puis revenez dans l'application. Vos notes seront rangées dans Documents/ObsiLan, visibles dans l'application Fichiers.

Si vous préférez refuser cet accès, ObsiLan propose son stockage interne : tout fonctionne, mais les notes ne sont alors visibles que dans l'application.

Astuce : sur téléphone, un appui long sur une note ou un dossier ouvre le menu (renommer, supprimer…).

Activer la synchronisation

La synchronisation garde vos notes identiques sur votre PC et votre téléphone. L'accès se fait sur invitation, avec votre compte Discord.

  1. Dans ObsiLan, touchez Synchronisation : non connecté en bas de la barre latérale.
  2. Saisissez l'adresse du serveur qui vous a été communiquée.
  3. Touchez Se connecter avec Discord : votre navigateur s'ouvre sur Discord. Autorisez ObsiLan (seuls votre identifiant et votre nom d'utilisateur sont lus), puis revenez dans l'application.
  4. C'est tout. La synchro se fait ensuite automatiquement : à l'ouverture, toutes les minutes, et quelques secondes après chaque modification.

Répétez l'opération sur chaque appareil. L'indicateur en bas de la barre latérale montre l'état : Synchronisé, Synchronisation… ou Hors ligne.

Reprendre des notes Obsidian

ObsiLan utilise la même syntaxe qu'Obsidian ([[liens]], #tags, en-tête YAML). Sur PC, choisissez simplement le dossier de votre coffre Obsidian au premier lancement. Les réglages d'Obsidian (dossier .obsidian) ne sont pas modifiés.

Mettre à jour

Téléchargez la nouvelle version et installez-la par-dessus l'ancienne : vos notes et vos réglages sont conservés. Consultez les notes de version pour voir les nouveautés.

Questions fréquentes

Mes notes sont-elles perdues si je désinstalle l'application ?

Non. Les notes sont des fichiers dans votre dossier (Documents\ObsiLan sur PC, Documents/ObsiLan sur Android) et y restent.

Et si je modifie la même note sur deux appareils hors ligne ?

À la synchro, les changements faits à des endroits différents sont fusionnés. Si la même ligne a été modifiée des deux côtés, la note garde une version et l'autre est enregistrée à côté, dans une note « … (conflit date appareil) ». Rien n'est perdu.

Où vont les notes supprimées ?

Dans le dossier caché .trash de votre dossier de notes, comme dans Obsidian.
